Chrome extension · Preview

Review a paper with Echo.

Install the preview · v0.2.2

Download the Chrome extension ZIP

  1. Unzip the download into a folder you will keep.
  2. Open chrome://extensions in Chrome and enable Developer mode.
  3. Choose Load unpacked and select the folder containing manifest.json.
  4. Open an HTML scientific paper and click the Echo extension icon in Chrome’s toolbar or extensions menu. The paper is captured automatically.
  5. Connect your capped OpenRouter key once, then choose a claim. Echo extracts pipeline claims automatically and runs the remaining review after your choice.

Updating an older version? Replace the files in your installed extension folder with the new ZIP contents, then click Reload on its card at chrome://extensions.

This preview is available only on permastaging. The download opens the permastaging review page; production use is disabled.

This is a preview, not a Chrome Web Store release. End-to-end evaluation on a real paper has not yet been verified. Reviews stay private unless you explicitly publish a schema. Model calls use your OpenRouter allowance.
