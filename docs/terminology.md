# Terminology

Words the interface uses, and what each one means. Use these in labels, help text, errors and exports. Code identifiers
(`group_id`, `finding_decisions`, `iv`/`dv`, `DAG` in file names) are unchanged.

| Word | Means | Not |
| --- | --- | --- |
| cause, outcome | The two variables the project asks about | Ind var / Dep var, independent / dependent variable, IV / DV |
| variable | A named set of related concepts | group, category, construct |
| concept | One of the lower-level items inside a variable | raw variable, member |
| claim | One specific finding extracted from a study | finding, evidence record |
| link | An arrow between two variables on the graph | edge |
| graph | The drawn network | DAG, causal diagram |
| map | The graph or its table equivalent | causal map |
| study | A paper in the evidence | paper |
| project | The user's own work | study |
| exclude | Take something out of the analysis (a concept, claim, link or variable) | remove, delete, hide |
| confounder status | How a potential confounder is handled; one of Unaddressed, Explicitly controlled, … | decision |
